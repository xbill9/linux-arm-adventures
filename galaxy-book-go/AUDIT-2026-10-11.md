# Galaxy Book Go audit: drivers, firmware, hardware, system tools (2026-10-11, about 11:10)

Unit: `Galaxy Book Go (Wi-Fi)/NP340XLA-KA3CA`, BIOS `P00AJW.036.230117.WY.1438` (2023-01-17). Debian 13, kernel `6.12.107+deb13-arm64`, the stick's DTB. Read-only checks over SSH. No LTE modem on this model ("Wi-Fi"); the modem remoteproc (`mpss`) still runs the Wi-Fi.

## Firmware

The DTB asks for four Samsung-signed files under `qcom/sc7180/samsung/galaxy-book-go/`. **None is installed.** Debian doesn't ship them; they come from Windows (`DriverStore`). This unit's Windows is gone, but the PNY Win11 stick holds `GBGo-Drivers/`, 117 driver folders harvested from a Book Go's `DriverStore` ([win11-stick/README.md](win11-stick/README.md)). Not yet checked whether those folders contain these files.

| DT asks for | Used by | Without it |
|---|---|---|
| `qcdxkmsuc7180.mbn` | GPU zap shader | `gpu hw init failed: -2`, software rendering (llvmpipe) |
| `qcmpss7180_nm.mbn` | modem DSP (`remoteproc@4080000`), which hosts the Wi-Fi firmware | remoteproc offline, **no Wi-Fi** |
| `qcadsp7180.mbn` | audio DSP (`remoteproc@62400000`). The DT path has a doubled slash (`sc7180//samsung`), harmless | remoteproc offline |
| `qcvss7180.mbn` | video codec (venus) | `qcom-venus … probe failed with error -22`, which also leaves the interconnects' `sync_state()` pending |

Also needed for Wi-Fi: `wlanmdsp.mbn` (served to the modem by `tqftpserv`), from the same Windows driver set.

From Debian packages, **not installed**:
- `firmware-atheros` (non-free-firmware): WCN3990 Wi-Fi board data (`ath10k/WCN3990/hw1.0/`) and the Bluetooth patches (`qca/crbtfw*.tlv`, `crnv*.bin`).
- ~~`qcom/a618_gmu.bin`~~: **wrong.** Kernel 6.12's `msm` uses `a630_gmu.bin` for the Adreno 618 (already installed). See [FIRMWARE.md](FIRMWARE.md).

|---|---|---|
| Display | works | `msm` + `panel_edp` + `ti_sn65dsi86`. `irq 134: nobody cared` from `ti_sn_bridge_interrupt`, so the kernel disabled that IRQ (bridge hotplug/HPD). **No backlight device**: no brightness control |
| GPU | no acceleration | zap shader + `a618_gmu.bin` missing |

| Wi-Fi | **missing** | `wifi@18800000` (`qcom,wcn3990-wifi`) is in the DT, but needs the modem firmware + `firmware-atheros` + `rmtfs`/`tqftpserv`/`qrtr-tools`/pd-mapper |

| USB-A, USB-C hub | works | AX88179 Ethernet, VIA hub, USB keyboard. `/sys/class/typec` empty (no UCSI) |
| Video codec | missing | firmware |
| Camera | none | no `/dev/video*` |
| Sensors | PMIC ADCs only | `iio:device0/1` (`pmic@0`, `pmic@4` ADC). Thermal zones present |
| Suspend | `s2idle` only | untested |
| Crypto engine, imem, TCSR, GMU | no driver | normal: used by other drivers or not needed |

## Installed 2026-10-11 11:12

`firmware-atheros` 20250410-2, `rmtfs`, `tqftpserv`, `qrtr-tools`, `device-tree-compiler`, `apt-listbugs`, `needrestart`, `i2c-tools`, `lm-sensors`, `ethtool`, `v4l-utils`, `curl`, `git`, `htop`, `btop`, `build-essential`, `chromium` 154 (116 packages with dependencies, nothing removed). Installed with `APT_LISTBUGS_FRONTEND=none NEEDRESTART_MODE=l`, so no service or the GNOME session was restarted.

- **Not installed: `timeshift`.** User decision: snapshots on the same UFS don't protect against what breaks these machines.
- **Not installed: `protection-domain-mapper`.** Kernel 6.12 has the in-kernel one (`CONFIG_QCOM_PD_MAPPER=m`); on the C630 the userspace one conflicted and had to be masked.
- Initramfs images unchanged (`302da1b2c0aa715f…` for 6.12.107, `dece49a40c4aa9a8…` for 6.12.111). Copies of both, with `SHA256SUMS`, are in `/boot/gbgo-known-good/` on the laptop.
- `rmtfs` and `tqftpserv` active, `systemctl --failed` empty.
- `firmware-atheros` brings `qca/crbtfw21.tlv`/`crnv21.bin` (Bluetooth; takes effect at the next boot, untested), `ath10k/WCN3990/hw1.0/board-2.bin`, `firmware-5.bin` and a generic `wlanmdsp.mbn`. **Wi-Fi now waits only on the Samsung modem firmware.**
